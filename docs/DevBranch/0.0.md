# 0.0.x
--- 

Latest changes and update to the direction of development.

> 0.0.8

After restructuring the roadmap of Almonds. We are going to focus more on the extraction aspect first before the base building element since base building and defending will be more of a passive side game of Almonds where extraction players with specific missions (TBD & WIP) may infiltrate into your world and target your base. Since those players are in extraction mode while you're in stronghold mode, defeating them wipes them from the server (TBD).

So the extraction game is priority and here are the changes.

- Matchmaking, queueing now puts you in a queue for nearby servers first determined by region for <60 seconds. If your lobby fills with 10+ players, the lobby will start. If it doesn't fill enough, you will be moved into a global queue for another 60s to find more players. It the lobby still doesn't fill, it will forcefully start game regardless of how many players in queue.
- Added safehome storages, Weapons Locker and General Stash. Weapons locker only stores weapons and general stash is only for general items. You can only infil and exfil with 2 guns and 1 melee for now.
- Environment now drops money instead of materials.
- Ammo and weapons are more common when killing bandits.
- Removed Loadouts system in replacement with safehome storages, to keep things simple, you can inventory manage in safehome world.
- Removed hunger and thirst element for extraction mode.
